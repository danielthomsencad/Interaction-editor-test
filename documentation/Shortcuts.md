# Keyboard Shortcuts & Mouse Actions

## Navigation

| Shortcut | Action |
|----------|--------|
| **Space + Drag** | Pan canvas |
| **Ctrl + Mouse Wheel** | Zoom in/out |
| **Ctrl** (hold) | Show zoom cursor |

## Editing

| Shortcut | Action |
|----------|--------|
| **Ctrl+C** | Copy selected element(s) and anchor points |
| **Ctrl+V** | Paste element(s) with 10px offset |
| **Ctrl+Z** | Undo last action or deletion |
| **Delete** | Delete selected element(s) |

## Selection

| Action | Result |
|--------|--------|
| **Click** | Select layer (interaction) |
| **Double-click** | Select individual element |
| **Drag** | Select multiple elements (box selection) |
| **Click empty area** | Clear selection |

## Creation Mode

| Shortcut | Action |
|----------|--------|
| **Shift+Click** | Place first vertex / Finalize and start new shape |
| **Click** | Place subsequent vertices |
| **Right-click** | Finalize current drawing |
| **Escape** | Finalize drawing or discard incomplete shape |
| **Ctrl+Z** | Undo last vertex in creation mode |

## Info Layer Mode

| Action | Result |
|--------|--------|
| **Click** | Select text or image element |
| **Double-click** | Edit text element |
| **Double-click (empty)** | Create new text at cursor |
| **Shift+Click** | Add popup image |
| **Drag** | Select multiple elements |

## General

- **Crosshair cursor**: Creation tool is active
- **Pointer cursor**: Mouse over selectable element
- **Grab cursor**: Space key held or pan mode active
- **Zoom cursor**: Ctrl key held
